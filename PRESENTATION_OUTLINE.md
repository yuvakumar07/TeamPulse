## Slide 12: Use Case #1 - Onboarding New Employee
**Title:** Scenario: New Employee Onboarding

**Workflow:**
1. **HR Initiates:** Click "Add Employee" button
2. **Enter Details:**
   - Basic information (Name, SSO, Role, Phone)
   - Visa information (Type, Dates, Passport)
   - Manager assignments
   - Skills and competencies
3. **Validation:** System validates required fields
4. **Asset Assignment:** Assign laptop, monitor, and other equipment
5. **Project Allocation:** Add to project team with allocation percentage
6. **Confirmation:** Employee profile created with audit trail

**Time Saved:** Reduces onboarding from hours to minutes

## Slide 17: Technical Architecture (High-Level)
**Title:** Built on Modern, Scalable Technology

**Technology Stack:**
- **Frontend:** React.js with PrimeReact UI library
- **Backend:** Node.js with Express.js
- **Database:** MySQL for reliable data storage
- **Authentication:** JWT-based secure authentication
- **Security:** Bcrypt password hashing, role-based access

**Architecture Benefits:**
- **Scalable:** Handles growing employee base
- **Responsive:** Works on desktop, tablet, and mobile
- **Secure:** Enterprise-grade security practices
- **Maintainable:** Modern codebase with best practices
- **Performant:** Optimized queries and lazy loading
